# دعوة زفاف عمر وحبيبة — دليل التعديل المختصر

## الروابط
| النسخة | المسار |
|---|---|
| الصورة الأمامية | `/front/` |
| الصورة الخلفية | `/back/` |

الجذر `/` يحوّل تلقائيًا إلى `/front/`، ولا توجد شاشة اختيار.

## أين أعدّل البيانات؟
كل البيانات والنصوص في ملف واحد: **`invite.config.json`**

| ما تريد تغييره | المفتاح |
|---|---|
| الأسماء | `couple.groom` / `couple.bride` |
| لحظة المناسبة (يُحسب منها العد التنازلي والتقويم) | `event.startLocal` بصيغة `2026-11-11T13:00:00+02:00` |
| النصوص الظاهرة للتاريخ والوقت | `event.dayName`، `dayMonth`، `year`، `timeLabel`، `timeZoneLabel`، `gateDate` |
| المكان ورابط الخريطة | `venue.name`، `venue.city`، `venue.calendarLocation`، `venue.mapUrl` |
| نصوص الظرف والدعوة | `texts.*` |
| عنوان ووصف المشاركة في واتساب | `share.title` / `share.description` |
| الرابط الأساسي للموقع (لصورة المعاينة) | `siteUrl` |

**تنبيه التوقيت:** اكتب `startLocal` بتوقيت مصر مع الإزاحة الصحيحة (`+02:00` شتاءً، `+03:00` إذا كان الموعد ضمن التوقيت الصيفي في مصر). أداة البناء تتحقق من الإزاحة وتنبّه عند الخطأ.

**الأرقام:** اكتبها إنجليزية دائمًا (0–9).

## بعد التعديل — طريقتان

### 1) من موقع GitHub مباشرة (بدون أي برامج)
1. افتح المستودع، ثم الملف `invite.config.json`، واضغط أيقونة القلم ✎.
2. عدّل، ثم اضغط **Commit changes**.
3. خلال دقيقة إلى دقيقتين تُبنى الدعوة وتُنشر على **نفس الروابط** تلقائيًا. يمكن متابعة ذلك من تبويب **Actions**.

### 2) من جهازك (يتطلب Node.js 18+)
```bash
node build.mjs          # ينتج المجلد _site/ (النسختين + ملف التقويم)
```
ثم ارفع التعديلات إلى الفرع `main`، والنشر يتم تلقائيًا.

> صورة المعاينة في واتساب تُخزَّن مؤقتًا لدى واتساب. إذا غيّرت العنوان أو الصورة ولم تتحدث المعاينة، أضف `?v=2` لنهاية الرابط عند مشاركته.

## تغيير الصور
- الصور في `assets/img/`: `front.png` و`front.webp`، و`back.png` و`back.webp`. استبدلها بنفس الأسماء وبنفس الأبعاد (1024×1536).
- صور المعاينة: `og-front.jpg` و`og-back.jpg`.
- الحرفان: `assets/img/monogram.png` (خلفية شفافة)، ويُستخدم في الختم وفي الدعوة.

## النقل إلى استضافة أخرى
بعد `node build.mjs` ارفع **محتوى** المجلد `_site/` كما هو إلى أي استضافة ملفات ثابتة (Netlify أو Cloudflare Pages أو غيرهما). كل المسارات نسبية، ولا يحتاج المشروع خادمًا أو قاعدة بيانات. اضبط `siteUrl` على الرابط الجديد قبل البناء حتى تعمل صورة المعاينة.

## ملاحظات
- الصفحة عليها `noindex` لمنع ظهورها في محركات البحث. هذا **ليس** حماية خصوصية: كل من يملك الرابط يستطيع فتحها.
- لا يوجد صوت، ولا تتبع، ولا نماذج تجمع بيانات.
- الخطوط محفوظة محليًا في `assets/fonts/` مع ترخيصها (SIL OFL 1.1).
- فحص آلي (اختياري): `node tests/verify.mjs http://localhost:8765/` بعد تشغيل خادم محلي على `_site/`، ويتطلب Playwright.
