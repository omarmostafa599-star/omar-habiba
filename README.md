# دعوة عقد قران عمر وحبيبة — دليل مختصر

## الروابط
| النسخة | المسار |
|---|---|
| الصورة الأمامية | `/front/` |
| الصورة الخلفية | `/back/` |

الجذر `/` يحوّل تلقائيًا إلى `/front/`.
للتجربة دون التأثير على الأرقام: أضف `?test=1` لنهاية الرابط.

## أين تظهر الردود؟
كل الردود تُحفظ في حسابك على Google:

| ماذا | أين |
|---|---|
| الأرقام لكل نسخة + الإجمالي (الزيارات، فتح الظرف، المؤكدون، المعتذرون، المباركات، التسجيلات، الفيديوهات، المساحة) | Google Sheet «دعوة عمر وحبيبة — الردود» ← ورقة **الملخص** |
| قائمة تأكيد الحضور | ورقة **الحضور** |
| المباركات مع روابط الصوت والفيديو | ورقة **المباركات** |
| الملفات الصوتية والفيديوهات | Google Drive ← مجلد **مباركات عمر وحبيبة** |

بيانات التجربة (`?test=1`) تُعلَّم بـ«نعم» في عمود «تجربة» ولا تدخل في الملخص.
**الذكرى:** من الشيت: ملف ← تنزيل ← Excel. ومن Drive: زر الفأرة الأيمن على المجلد ← تنزيل (ملف ZIP).

## أين أعدّل البيانات؟
كل البيانات والنصوص في ملف واحد: **`invite.config.json`**

| ما تريد تغييره | المفتاح |
|---|---|
| الأسماء | `couple.groom` / `couple.bride` |
| لحظة المناسبة (العد التنازلي والتقويم) | `event.startLocal` بصيغة `2026-11-11T12:00:00+02:00` |
| النصوص الظاهرة للموعد | `event.dayName`، `dayMonth`، `year`، `timeLabel`، `timeZoneLabel`، `ceremonyLine`، `gateDate` |
| المكان ورابط الخريطة | `venue.*` |
| كل نصوص الدعوة والنماذج | `texts.*` |
| عنوان ووصف المشاركة في واتساب | `share.title` / `share.description` |
| رابط استقبال الردود (Apps Script) | `backend.endpoint` (إن كان فارغًا تختفي أقسام الحضور والمباركات) |
| أقصى مدة للصوت / الفيديو، وأقصى حجم للفيديو | `backend.voiceMaxSeconds` / `videoMaxSeconds` / `videoMaxMB` |
| الرابط الأساسي للموقع (لصورة المعاينة) | `siteUrl` |

**تنبيه التوقيت:** اكتب `startLocal` بتوقيت مصر مع الإزاحة الصحيحة (`+02:00` شتاءً). أداة البناء تتحقق وتنبّه.
**الأرقام:** إنجليزية دائمًا (0–9).

## بعد التعديل
1. في GitHub افتح `invite.config.json` واضغط ✎، عدّل، ثم **Commit changes**.
2. خلال دقيقة إلى دقيقتين تُبنى الدعوة وتُنشر على **نفس الروابط** (تابع من تبويب **Actions**).

من الجهاز (Node.js 18+): `node build.mjs` ينتج المجلد `_site/`.

> واتساب يحفظ معاينة الرابط مؤقتًا. إن غيّرت العنوان أو الصورة ولم تتحدث المعاينة، أضف `?v=2` لنهاية الرابط عند مشاركته.

## سكربت استقبال الردود (Google Apps Script)
الكود في `apps-script/Code.gs` (والإعدادات في `apps-script/appsscript.json`).
- الإعداد لأول مرة: الصق الكود في مشروع Apps Script ← شغّل `setup` ← Deploy ← New deployment ← Web app (Execute as: Me · Who has access: Anyone) ← ضع رابط `/exec` في `backend.endpoint`.
- لتحديث الكود لاحقًا **بنفس الرابط**: Deploy ← Manage deployments ← ✎ ← Version: New version ← Deploy.
- الضيف يستطيع الإضافة فقط ولا يرى أي بيانات. الشيت والمجلد خاصّان بحسابك.

## تغيير الصور
- `assets/img/front.*` و`back.*` (1024×1536)، وصور المعاينة `og-front.jpg` و`og-back.jpg`.
- الظرف: `doors.jpg` (الضلفتان) و`liner.jpg` (البطانة) و`seal.png` (الختم).
- المسجد: `mosque.jpg` و`mosque.webp`.
- الحرفان: `monogram.png` (يُستخدم قناعًا بلون النص على الختم وفي الدعوة).

## ملاحظات
- الصفحة عليها `noindex` لمنع ظهورها في محركات البحث، وهذا **ليس** حماية خصوصية.
- لا موسيقى ولا إعلانات ولا أدوات تتبع خارجية. العداد مجهول (معرّف عشوائي للجهاز فقط).
- الخطوط محلية في `assets/fonts/` مع ترخيصها (SIL OFL 1.1).
- فحص آلي (اختياري، يتطلب Playwright):
  `node tests/mock-gas.mjs 8766` ثم `INVITE_ENDPOINT=http://localhost:8766/exec node build.mjs` وخادم محلي على `_site/`، ثم
  `node tests/verify.mjs http://localhost:8765/` و`node tests/features.mjs http://localhost:8765/ http://localhost:8766`.
